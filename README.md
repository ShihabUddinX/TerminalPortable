# Terminal Portable (Dev Test)

## ⚙️ Overview

**Terminal Portable (Dev Test)** is a **development build** of the modern Windows Terminal app repackaged for PortableApps.com.
It delivers a powerful, tabbed terminal experience that supports PowerShell, Command Prompt, and WSL — all without installation.
This version is currently in **Dev Test** stage, meaning it's under testing and may have minor bugs or unfinished features.

## 🧪 Current Status

- 🧩 **Stage:** Development Test (Unofficial / Testing)
- 🆚 **Version:** v1.24.10621.0 Dev Test 1
- 📅 **Published at:** [PortableApps.com](https://portableapps.com/node/79548)
- 🚧 **Note:** This is *not yet an official PortableApps.com release.*

## 🔍 Features

- Multi-tab terminal (PowerShell, CMD, WSL)
- Open-source, lightweight, and customizable
- Portable — no installer or registry changes
- JSON-based configuration for themes & profiles
- Unicode and emoji support
- Actively maintained upstream by Microsoft

## 🛠️ Getting Started

1. Download **Terminal Portable (Dev Test)** from [PortableApps.com](https://portableapps.com/node/79548).
2. Extract or run the `.paf.exe` file from your USB drive or desired folder.
3. Launch `TerminalPortable.exe`.
4. Choose your preferred shell — PowerShell, CMD, or WSL — and start working instantly!

## 💡 Why Portable?

- **No Installation Needed:** Perfect for testing environments or restricted PCs
- **Developer Friendly:** Keep your portable terminal setup for scripting or admin use
- **No Trace:** Leaves nothing on the host system
- **Easy Testing:** Great for early adopters and testers to provide feedback

## 🧭 Usage Tips

- Store it on a fast USB 3.0 or SSD for smoother performance
- Edit `settings.json` to customize colors, profiles, and keybindings
- For WSL, make sure it’s enabled on the host system
- Keep backups of your config for future builds
